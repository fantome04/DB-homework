# Top SQL 50 Practice

This directory contains the SQL exercises that were previously tracked only as GitHub issues.

## Organization

Each file is named using the LeetCode problem number and title:

```text
1757-recyclable-and-low-fat-products.sql
0584-find-customer-referee.sql
...
1517-find-users-with-valid-e-mails.sql
```

Every SQL file includes:

- the original GitHub issue;
- the original LeetCode submission link when it was present in the issue;
- a readable SQL solution.

> Note: GitHub exposes the saved LeetCode submission URLs, but the connected repository API does not expose the private contents of those LeetCode submissions. The SQL source files in this directory are equivalent correct solutions reconstructed for the same problems, while the original submission links are preserved for traceability.

## Main Concepts

- Basic SELECT and filtering
- JOINs
- GROUP BY and HAVING
- Aggregation
- Subqueries
- Date operations
- String processing
- Conditional expressions
- Regular expressions
- Data modification
