# Database Systems Practice

University coursework and hands-on database exercises covering SQL, relational database design, normalization, and ScyllaDB.

## Contents

- `sql/top-sql-50/` — 41 SQL solutions from the LeetCode Top SQL 50 study plan
- `normalization/` — normalization coursework and original submission reference
- `scylladb/` — ScyllaDB coursework and original assignment reference
- `ORIGINAL_SUBMISSIONS.md` — preserved links to the original GitHub issues and LeetCode submissions

## Topics

- SELECT, filtering, and sorting
- JOINs
- Aggregation and grouping
- Subqueries
- Date and string operations
- Conditional expressions
- Relational database design
- Normalization
- ScyllaDB / CQL

## SQL Practice

The SQL exercises were originally tracked as GitHub issues with links to accepted LeetCode submissions. They are now stored as source files so the work is visible directly from the repository.

Each solution file includes a reference to its original issue and submission link.
